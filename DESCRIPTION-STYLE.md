# Формулювання описів зброї

Описи пояснюють чинні рекомендації каталогу. Редагування стилю не є новою перевіркою білду й не змінює його оцінки чи дату перевірки.

- Однаковий зміст передавати однаково. Конкретні відмінності зброї додавати окремим реченням.
- Українською: «статус», «шанс статусу», «періодична шкода», «шкода по площі», «альтернативна атака», «удар об землю», «перезаряджання». Не чергувати їх із «прок», DoT, AoE, alt-fire, slam або випадковими англійськими назвами шкоди.
- Російською: «статус», «шанс статуса», «периодический урон», «урон по площади», «альтернативная атака», «удар о землю», «перезарядка».
- Назви модів і містифікаторів зберігати з джерела. Melee Influence писати повністю; Hunter Munitions не скорочувати до HM. Не вгадувати повну назву інших скорочень.
- «Вірусна шкода одним модом» та «вірусна шкода без модів» означають різні умови. Не зводити їх до одного шаблону. Те саме стосується вродженої шкоди, додаткового статусу й гарантованого статусу.
- Пояснення рекомендації: бонус → причина; альтернативу описувати наступним реченням. Короткий опис механіки завершувати крапкою. Оцінку матриці S/A/B/C/D зберігати перед « • ».
- Зберігати UK/EN/RU поля, назви зброї, порядок, бонуси, оцінки, URL та дати. Англійські авторські описи зараз порожні; чинне відображення українського тексту з попередженням зберігається.

Приклади спільних формулювань:

| Зміст | Українська | Російська |
| --- | --- | --- |
| Незмінні комбінації модів | Магнетична не змінює комбінації стихій із модів. | Магнит не меняет комбинации стихий от модов. |
| Поширення статусів | Електрична активує Melee Influence для поширення статусів між ворогами. | Электричество активирует Melee Influence для распространения статусов между врагами. |
| Універсальний бонус | Магнетична підходить як універсальний бонус. | Магнит подходит как универсальный бонус. |
